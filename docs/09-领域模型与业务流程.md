## 1. 核心业务流程（端到端）

```
客户询价 ─► 报价 ─► 接单(销售订单) ─► 印前(文件预检/拼版/CTP) ─► 工艺(工艺卡/物料BOM)
   │                                          │
   └────────── 排产(APS) ◄── 采购(纸张/油墨/版材) │
                 │
                 ▼
            生产(工单/MES/设备采集) ─► 质检(色差ΔE/套准/外观) ─► 仓储 ─► 发运 ─► 对账(结算/开票)
                 │                              │
                 └──── 外协(覆膜/烫金/模切/装订) ──┘
```

- 主线单据流转：`报价单 → 销售订单 → 生产工单 → 工艺卡/拼版方案 → 外协单/采购单 → 质检单 → 发运单 → 对账单 → 成本单`。
- **可逆与例外**：质检不合格回退工单返工；外协延迟触发重排产；对账差异触发客诉归因（见 [`08`](./08-AI能力与生成型特性.md) 客诉归因）。

## 3. 三大引擎详细设计

### 3.1 报价引擎（规则引擎 + 历史价回归）

- **组成**：Drools/Aviator 外置规则（业务可自助改）+ 历史成交价回归模型（AI 侧，见 [`08`](./08-AI能力与生成型特性.md)）。
- **输入**：成品尺寸、页数、印数、纸张（克重/品种）、色别（单色/四色/专色）、后道工序。
- **计算链路**：开数 → 用纸量 → 纸张成本 → 印工 → 后道 → 税/利润 → 报价。

**报价公式示例（书刊，双面单色内页 + 胶装封面）**

```
① 出血后尺寸 = 成品尺寸 + 2×出血(每边 3mm)
   例: 成品 210×285 → 拼版尺寸 216×291

② 开数 K = 单张印刷纸可排成品个数(考虑咬口 8–15mm、刀距 3mm、拉规)
   例: 对开 595×885 拼 216×291 → K = 2×3 = 6(含咬口取整后常取 4 或 6)

③ 单册印张数(对开) = ceil(总页数 / 2)
   例: 内页 64P → 64/2 = 32 印张

④ 用纸量(令) = 单册印张数 × 印数 / 500 × (1 + 放损率)
   放损率: ≤500 本 8% | 501–2000 本 5% | 2001–5000 本 4% | >5000 本 3%
   (另计每色放数: 单色每版 30–50 张校版)

⑤ 令重(kg) = 纸长(m) × 纸宽(m) × 克重(g/m²) × 500 / 1000
   例: 大度 889×1194、80g → 0.889×1.194×80×500/1000 ≈ 42.45 kg/令

⑥ 令价(元) = 吨价(元/吨) / 1000 × 令重(kg)
   例: 吨价 6200 → 6200/1000×42.45 ≈ 263.19 元/令

⑦ 纸张成本 = 用纸量(令) × 令价
   例: 印数 2000、32 印张、放损 5%
      用纸 = 32×2000/500×1.05 = 134.4 令 → 纸张成本 = 134.4×263.19 ≈ 35,372 元

⑧ 色令数 = 单册印张数 × 印数 / 500 × 色数(正+反)
   例: 双面单色 → 色数=2 → 色令 = 32×2000/500×2 = 256 色令

⑨ 印工费 = 色令数 × 色令单价 + 起印费(每版)
   例: 色令单价 45 元 → 256×45 + 起印费 ≈ 11,520 + 起印费

⑩ 后道费 = Σ(工序单价 × 数量)   # 折页/胶订/覆膜/模切/烫金
⑪ 报价 = (纸张 + 印工 + 后道 + 版费/CTP) × (1 + 管理费率) × (1 + 税率) × (1 + 目标利润率)
```

- **回退校验**：规则价与历史回归价偏差 > 3% 时告警，交人工复核（与 [`08`](./08-AI能力与生成型特性.md) §5 一致）。

### 3.2 拼版/开纸引擎（排样算法 + 约束优化 + G6 可视化）

- **输入**：成品尺寸 + 出血 + 咬口、印数、纸张规格、折手（折页方式）。
- **算法**：二维排样（矩形装箱启发式：左下角 BL + 遗传/局部搜索优化利用率）+ 约束（咬口≥8mm、出血不重叠、刀距≥3mm、丝缕方向、双面套准）。
- **输出**：开数 K、纸张利用率、拼版图、开纸方案（大张→对开→开料尺寸）。
- **可视化**：AntV G6 渲染拼版图 + 利用率热力标注；方案保存为 `Imposition` 聚合，可复现、可改。
- **AI 增强**：AI 从成品尺寸直接给初始拼版方案，引擎精确校验并回填开数/利用率（见 [`08`](./08-AI能力与生成型特性.md)）。

### 3.3 APS 排产引擎（约束满足 + 启发式，甘特）

- **输入**：工单（交期/工艺路线/颜色组）、机台（产能/换版换纸时间/可印刷色组）、物料齐套、外协依赖。
- **约束**：交期硬约束、机台互斥、工序顺序、换版/换纸/换墨时间、同色序合并、外协前置。
- **算法**：约束满足（CSP）建模 + 遗传/局部搜索启发式求准优解；超载时输出交期风险与建议。
- **输出**：机台甘特图（G6），订单级排产明细；与 MES/设备采集打通回填实际开工/完工。
- **AI 增强**：AI 排产建议 + 交期风险预测，但**不可执行**需计划员确认（见 [`08`](./08-AI能力与生成型特性.md)）。

## 4. 外协 / 供应商 / 质检 / 财务成本核算

- **外协**：`OutsourcingOrder` 生命周期 `创建→发出→外协厂接收→完工回厂→质检`；工序照片/文件上传（协同端），状态回写工单。
- **供应商**：`PurchaseOrder` + `Supplier` 报价比价（见 [`08`](./08-AI能力与生成型特性.md) 比价）；纸张按批次入库。
- **质检**：`QualityCheck` 记录色差 `ColorDelta(ΔE)`、套准、外观、耐折；判定不合格 → 返工/让步接收（需审批）。
- **财务成本核算**：`CostSheet` 归集直接成本（纸张/油墨/印工/后道/外协）+ 分摊（机时/人工/管理费）；`Statement` 对账差异逐行归因。

---

## 5. JDF/JMF 与设备物联预留

- **JDF/JMF（CIP4）**：印前-印刷-印后数据交换预留。一期：`integration` 模块提供 JDF 解析适配器接口 + 最小 JMF 消息骨架；与 CTP、印刷机、切纸机的对接作为 `integration` 外部系统插件。
- **设备物联（MES/OEE）**：机台计数/状态通过 OPC-UA/MQTT 采集写入 `production` 模块，供 APS 回填与 OEE 计算（指标见 [`10`](./10-迭代进化与度量.md)）。一期仅预留采集表结构与抽象，不绑定具体设备协议。

## 6. 数据库关键表结构示例（DDL 片段）

> 命名遵循 [`_conventions.md`](./_conventions.md) 第 4 节：表 `snake_case` 复数、时间列 `<verb>_at`、布尔 `is_/has_`、外键 `<table_singular>_id`。

```sql
-- 销售订单
CREATE TABLE sales_orders (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id         BIGINT NOT NULL,
  customer_id       BIGINT NOT NULL REFERENCES customers(id),
  order_no          TEXT NOT NULL UNIQUE,
  status            TEXT NOT NULL DEFAULT 'draft',   -- draft/submitted/confirmed/in_production/shipped/settled
  promised_at       TIMESTAMPTZ,
  latest_at         TIMESTAMPTZ,
  total_amount      NUMERIC(14,2) NOT NULL DEFAULT 0,
  currency          CHAR(3) NOT NULL DEFAULT 'CNY',
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 报价单（明细含规则价/成交价，供 AI 回归）
CREATE TABLE quotations (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id         BIGINT NOT NULL,
  sales_order_id    BIGINT REFERENCES sales_orders(id),
  rule_price        NUMERIC(14,2) NOT NULL,
  quoted_price      NUMERIC(14,2) NOT NULL,
  waste_rate        NUMERIC(6,4) NOT NULL DEFAULT 0.05,  -- 放损率
  price_version     TEXT NOT NULL,                        -- 规则引擎版本
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 工艺卡（工序 JSONB 存路线）
CREATE TABLE craft_sheets (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id         BIGINT NOT NULL,
  work_order_id     BIGINT REFERENCES work_orders(id),
  route             JSONB NOT NULL,        -- [{operation_type, machine_id, params, seq}]
  bom               JSONB NOT NULL,
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 拼版方案（G6 可视化数据 + 利用率）
CREATE TABLE impositions (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id         BIGINT NOT NULL,
  work_order_id     BIGINT REFERENCES work_orders(id),
  up_count          INT NOT NULL,          -- 开数
  sheet_size        TEXT NOT NULL,         -- 纸张规格
  layout            JSONB NOT NULL,        -- 排样坐标(供 G6 渲染)
  utilization       NUMERIC(6,4) NOT NULL, -- 纸张利用率
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 质检单（色差 ΔE 记录）
CREATE TABLE quality_checks (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id         BIGINT NOT NULL,
  work_order_id     BIGINT REFERENCES work_orders(id),
  delta_e           NUMERIC(6,2),         -- 色差 ΔE
  verdict           TEXT NOT NULL,         -- passed/failed/concession
  checked_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- AI 追踪（只增不改，见 08 §7）
CREATE TABLE ai_traces (
  id                BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id         BIGINT NOT NULL,
  trace_id          TEXT NOT NULL UNIQUE,
  agent             TEXT NOT NULL,
  prompt_version    TEXT NOT NULL,
  model             TEXT NOT NULL,
  input_snapshot    JSONB NOT NULL,        -- 脱敏后
  output_snapshot   JSONB NOT NULL,
  human_verdict     TEXT,                  -- approved/rejected
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

## 7. 领域事件清单

> 命名遵循 [`_conventions.md`](./_conventions.md) 第 4 节 `<domain>.<aggregate>.<past-tense-verb>`；经 RocketMQ 事务消息发布（订单-库存-工单一致性）。

| 事件 | 语义 | 消费方（示例） |

| `quotation.quotation.priced` | 报价完成 | 销售订单、AI 回归样本 |

| `order.sales-order.confirmed` | 订单确认 | 工单创建、采购 |

| `craft.craft-sheet.generated` | 工艺卡生成 | APS、成本 |
| `imposition.imposition.generated` | 拼版方案生成 | 物料、CTP |
| `aps.schedule.published` | 排产发布 | 生产、交期问答 |
| `production.work-order.started` / `completed` | 工单开工/完工 | OEE、交期 |
| `material.paper-stock.reserved` / `consumed` | 纸张预留/消耗 | 库存、成本 |
| `outsourcing.outsourcing-order.dispatched` / `received` | 外协发出/回厂 | 工单、质量 |
| `quality.quality-check.passed` / `failed` | 质检结论 | 仓储、工单返工 |
| `warehouse.shipment.shipped` / `delivered` | 发运/签收 | 对账 |
| `finance.statement.generated` / `settled` | 对账生成/结清 | 客诉归因 |
| `finance.cost-sheet.calculated` | 成本归集完成 | 报表、毛利 |
