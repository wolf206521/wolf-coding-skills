# 方案文档索引

本文档集以「印刷行业生成型 ERP（P-ERP）」为落地示例，阐述大型企业级软件项目的全过程方案；方法论本身与行业无关，可迁移到任何大型项目。

> 先读 [`_conventions.md`](./_conventions.md)（唯一事实源），再读 [`00-master-plan.md`](./00-master-plan.md)（总纲）。
