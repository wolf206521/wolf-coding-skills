## 拆分提示

- 长配置/完整示例 → 移入 `reference/<主题>.md`，SKILL.md 用 `./reference/...` 链接引用。
- 要运行的命令逻辑 → 移入 `scripts/`，SKILL.md 写明「执行 `scripts/xxx`」。
- 要复制到目标项目的文件 → 移入 `assets/`，SKILL.md 写明「从 `assets/` 拷贝」。
