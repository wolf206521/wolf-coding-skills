# 双周回顾模板（细节参考）

> 承载 `SKILL.md` 阶段 2 的可复用模板。直接复制到回顾文档，按 60 分钟节奏走。

## 议程（60 分钟）

| 时间 | 环节 | 产出 |
| --- | --- | --- |
| 0–10 | 读数据 | 四维度指标环比，标出 >20% 变化项 |
| 10–25 | Keep / Problem / Try | 每人 3 条，贴板分类 |
| 25–40 | 根因分析 | Problem 逐条做「5 Why」 |
| 40–50 | 收敛行动项 | Try → SMART |
| 50–60 | 定债 + 回顾自身 | 技术债登记 + 回顾质量自评 |

## SMART 行动项模板

```
行动项：<一句话>
负责人：<name>
期限：<日期>
可验证产出：<如何证明完成，例如"覆盖率从 58% 升到 70%，CI 报告可见">
来源：<来自哪个 Problem>
```

## 技术债登记卡

```
ID: DEBT-<迭代>-<序号>
级别: P0/P1/P2/P3
描述: <一句话>
影响: <对交付/质量/业务的影响>
处置: 立即 / 本迭代 / 20%预算 / 顺路
owner: <name>
状态: 待办 / 进行中 / 已偿清
```

## 回顾质量自评（会后 1 分钟）

- [ ] 本轮每个 Problem 都有根因，每个 Try 都 SMART。
- [ ] 上轮行动项闭环率已计算并说明未闭环原因。
- [ ] 本轮回填了 ADR / 技术债看板。
